# Tested shader packs

Every pack below was converted and compiled program by program with Aetherium 0.1.0 on 2026-10-06. Every program in
every pack compiled. The Distant Horizons programs (`dh_*`) are the only exception, because they are only built while
Distant Horizons is installed and are checked separately.

The **Verdict** column is from playing with the pack in a test world:

- **Works:** no differences found.
- **Minor issues:** see the notes.
- **Broken:** not usable yet.
